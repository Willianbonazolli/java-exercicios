# Java Exercícios

Este repositório reúne alguns dos exercícios práticos de Java que eu considero interessantes para você treinar se estiver aprendendo Java, eles estão organizados por nível de dificuldade.

## Estrutura

- 01-fundamentos: operadores, entrada/saída e cálculos básicos
- 02-condicionais-loops: condicionais, laços e lógica de repetição
- 03-arrays: arrays, matrizes e ordenação
- 04-orientacao-objetos: projetos com classes, objetos e encapsulamento
- 05-projetos: mini projetos integrados

## Como executar

1. Abra o projeto em um editor Java como VS Code ou IntelliJ.
2. Compile o arquivo com:
   ```bash
   javac NomeDaClasse.java
   ```
3. Execute com:
   ```bash
   java NomeDaClasse
   ```

## Objetivo

Praticar conceitos fundamentais de Java por meio de pequenos exercícios e projetos.
