## Como executar os arquivos .JAVA

**Pré-requisito:** [JDK](https://www.oracle.com/java/technologies/downloads/) instalado e configurado.
 
1. Abra o projeto em um editor Java, como Eclipse ou IntelliJ.
2. Compile o arquivo desejado:
```bash
   javac NomeDaClasse.java
```
3. Execute:
```bash
   java NomeDaClasse
```
