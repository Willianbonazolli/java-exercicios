1. Conceitos Básicos

Java é uma linguagem amplamente utilizada no desenvolvimento de aplicações. Sua estrutura permite trabalhar desde pequenos programas executados no terminal até sistemas web, aplicações empresariais e soluções distribuídas.

Um programa Java é organizado a partir de classes, que podem conter atributos e métodos. Conforme o projeto cresce, essas classes podem ser agrupadas em pacotes, ajudando a separar responsabilidades e manter o código organizado.

Aprender Java não envolve apenas conhecer a sintaxe. É importante desenvolver a capacidade de transformar um problema em etapas que possam ser representadas por algoritmos e, posteriormente, implementadas em código.

Variáveis

Uma variável representa um espaço utilizado pelo programa para armazenar uma informação. Java utiliza tipagem estática: o tipo do dado é declarado junto com a variável.

Entre os tipos mais utilizados estão:

Tipo Utilização
byte Pequenos números inteiros
short Números inteiros de menor capacidade
int Inteiros utilizados na maioria dos programas
long Inteiros que podem atingir valores muito grandes
float Valores decimais
double Valores decimais com maior precisão
char Um único caractere
boolean Valores true ou false

Exemplos de declaração:

int quantidade = 15;
long populacao = 214000000L;
double salario = 2850.75;
char inicial = 'W';
boolean ativo = true;

Operadores Aritméticos

Java fornece os operadores aritméticos comuns. O operador %, chamado módulo, retorna o resto da divisão inteira e é bastante utilizado para verificar paridade e calcular divisores. 

int a = 10, b = 3;
System.out.println(a + b);  // 13
System.out.println(a - b);  // 7
System.out.println(a * b);  // 30
System.out.println(a / b);  // 3, divisão inteira
System.out.println(a % b);  // 1, resto

Para cálculos matemáticos mais complexos, a classe Math fornece constantes e métodos prontos. 

double area = Math.PI * Math.pow(raio, 2); // π × r²
double raiz = Math.sqrt(25);               // 5.0

Além dos tipos primitivos, é possível trabalhar com objetos como String. 

String cidade = "Cuiabá";

Operações com Strings

Strings possuem métodos que permitem consultar e manipular seu conteúdo. Veja alguns dos métodos mais utilizados:

length()

Retorna a quantidade de caracteres da String.

String curso = "Engenharia de Software";
System.out.println(curso.length()); // Resultado: 23

toUpperCase() e toLowerCase()

Alteram as letras da String para maiúsculas ou minúsculas.

String curso = "Engenharia de Software";

System.out.println(curso.toUpperCase()); // Resultado: ENGENHARIA DE SOFTWARE

System.out.println(curso.toLowerCase()); // Resultado: engenharia de software

contains()

Verifica se a String contém determinada sequência de caracteres. O resultado é um valor boolean: true ou false. 

String curso = "Engenharia de Software";

System.out.println(curso.contains("Software")); // Resultado: true

System.out.println(curso.contains("Java")); // Resultado: false

replace()

Substitui uma sequência de caracteres por outra.

String linguagem = "Eu estudo Java";

String resultado = linguagem.replace("Java", "Python");

System.out.println(resultado); // Resultado: Eu estudo Python

substring()

Obtém uma parte da String a partir de uma posição inicial. Também é possível informar uma posição final. 

String curso = "Engenharia de Software";

System.out.println(curso.substring(0, 11)); // Resultado: Engenharia

System.out.println(curso.substring(12)); // Resultado: de Software
Resumo dos métodos
  • length(): retorna a quantidade de caracteres;
  • toUpperCase(): converte para letras maiúsculas;
  • toLowerCase(): converte para letras minúsculas;
  • contains(): verifica se um trecho está presente;
  • replace(): substitui uma sequência de caracteres;
  • substring(): obtém uma parte da String.

Como ler dados do teclado em Java?

Para capturar entradas do usuário no terminal, utilizamos a classe Scanner do pacote java.util. 

import java.util.Scanner;

public class Exemplo {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.print("Digite seu nome: ");
        String nome = sc.nextLine();

        System.out.print("Digite sua idade: ");
        int idade = sc.nextInt();

        System.out.print("Digite seu salário: ");
        double salario = sc.nextDouble();

        System.out.println(
            "Olá, " + nome + "! Idade: " + idade
        );

        sc.close();
    }
}

Use nextLine() para texto, nextInt() para inteiros e nextDouble() para valores decimais. Ao finalizar o uso do Scanner, feche-o com sc.close().

2. Condições e Repetições

Programas raramente executam sempre as mesmas instruções. O if permite executar um trecho somente quando uma condição é verdadeira. 

if (idade >= 18) {
    System.out.println("Acesso permitido");
} else {
    System.out.println("Acesso negado");
}

Para múltiplas possibilidades, use else if.

if (nota >= 9) {
    System.out.println("Excelente");
} else if (nota >= 7) {
    System.out.println("Bom");
} else {
    System.out.println("Precisa melhorar");
}

O switch é útil quando comparamos uma variável com valores fixos conhecidos. 

switch (opcao) {

    case 1:
        System.out.println("Cadastrar");
        break;

    case 2:
        System.out.println("Consultar");
        break;

    default:
        System.out.println("Opção inválida");
}

Operadores Relacionais e Lógicos

Operadores relacionais utilizados para comparar valores:

==   igual
!=   diferente
>    maior
<    menor
>=   maior ou igual
<=   menor ou igual

Operadores lógicos utilizados para combinar condições:

&&   E, ambas verdadeiras
||   OU, pelo menos uma verdadeira
!    NÃO, inverte o resultado

Estruturas de Repetição

O for é ideal quando a quantidade de repetições é conhecida. 

for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

O while repete enquanto uma condição for verdadeira.

while (saldo > 0) {
    saldo -= 100;
}

O do while executa o bloco pelo menos uma vez antes de verificar a condição. 

do {
    System.out.println("Menu");
} while (opcao != 0);

As palavras break e continue controlam o fluxo dentro de loops. 

for (int i = 2; i <= numero; i++) {

    if (numero % i == 0) {
        primo = false;
        break;
    }
}

3. Vetores e Matrizes

Quando precisamos trabalhar com vários valores relacionados, arrays permitem armazenar múltiplos elementos do mesmo tipo em uma única estrutura. 

double[] temperaturas = {
    24.5,
    25.8,
    26.1,
    23.9
};

O primeiro elemento está na posição 0. Para criar um array de tamanho fixo: 

int[] valores = new int[5];
// cinco posições, todas inicialmente com 0

Percorrendo um Vetor

// For com índice: útil quando o índice importa
for (int i = 0; i < valores.length; i++) {
    System.out.println(valores[i]);
}

// For-each: útil quando apenas o valor é necessário
for (int valor : valores) {
    System.out.println(valor);
}

Matrizes

Uma matriz organiza informações em linhas e colunas.

int[][] tabela = {
    {10, 20, 30},
    {40, 50, 60}
};

for (int linha = 0; linha < tabela.length; linha++) {

    for (int coluna = 0;
         coluna < tabela[linha].length;
         coluna++) {

        System.out.print(tabela[linha][coluna] + " ");
    }

    System.out.println();
}

4. Coleções: ArrayList

Arrays possuem tamanho fixo. Uma vez criados, não é possível adicionar ou remover posições. Para listas dinâmicas, Java oferece o ArrayList, que pode crescer e diminuir conforme necessário.

Para usar um ArrayList, importe a classe e declare o tipo dos elementos entre <>. 

import java.util.ArrayList;

ArrayList<String> nomes = new ArrayList<>();

Operações Básicas

nomes.add("Ana");
nomes.add("Bruno");
nomes.add("Carla");

System.out.println(nomes.get(0));
System.out.println(nomes.size());
System.out.println(nomes.contains("Ana"));

nomes.remove(1);
nomes.remove("Carla");

Percorrendo um ArrayList

O for-each funciona da mesma forma que com arrays.

for (String nome : nomes) {
    System.out.println(nome);
}

ArrayList com Objetos

Podemos armazenar qualquer tipo de objeto, inclusive classes que criamos. 

import java.util.ArrayList;

ArrayList<Produto> estoque = new ArrayList<>();

estoque.add(
    new Produto("Teclado", 150.00)
);

estoque.add(
    new Produto("Mouse", 80.00)
);

for (Produto p : estoque) {
    p.exibirInformacoes();
}
Array ou ArrayList?

Use array quando o número de elementos é fixo e conhecido, como sete dias da semana ou uma matriz 3×3.

Use ArrayList quando a lista precisa crescer ou diminuir durante a execução do programa. Essa situação é comum em cadastros, menus e sistemas.

5. Programação Orientada a Objetos

A programação orientada a objetos, conhecida como POO, permite estruturar uma aplicação utilizando entidades com dados e comportamentos.

Uma classe funciona como um modelo. Um objeto é uma instância desse modelo. 

Funcionario f = new Funcionario();

Atributos

Atributos representam as características de um objeto.

class Produto {

    String nome;
    double preco;
    int quantidade;
}
Atenção: modificadores de acesso

Atributos sem modificador utilizam acesso de pacote (package-private), permitindo acesso por classes do mesmo pacote.

Na prática, é recomendado declarar atributos como private e fornecer métodos de acesso, como getters e setters.

Métodos

Métodos representam ações que o objeto pode executar. Um método pode retornar um valor ou não. 

// Método sem retorno
void exibirNome() {
    System.out.println(nome);
}

// Método com retorno
double calcularSalarioAnual() {
    return salario * 12;
}

boolean estaAtivo() {
    return ativo;
}

O tipo de retorno pode ser qualquer tipo primitivo, como int, double e boolean, ou qualquer classe, como String e Produto.

Use void quando o método não precisa devolver um valor.

Construtores

O construtor inicializa o objeto no momento da criação.

public Produto(String nome, double preco) {

    this.nome = nome;
    this.preco = preco;
}

// Uso
Produto teclado = new Produto("Teclado", 150.00);

Encapsulamento

Proteja os atributos com private e exponha apenas o que for necessário por meio de métodos. 

class Conta {

    private double saldo;

    public double getSaldo() {
        return saldo;
    }

    public void depositar(double valor) {

        if (valor > 0) {
            saldo += valor;
        }
    }
}

6. Projetos Práticos

Nesta etapa, você colocará em prática os conhecimentos estudados ao longo da apostila por meio de projetos maiores. Cada projeto apresenta uma situação diferente e possui funcionalidades que devem ser implementadas.

Desenvolva uma aplicação para organizar tarefas do dia a dia. O usuário deverá conseguir cadastrar tarefas e acompanhar quais atividades ainda precisam ser realizadas.

Como desafio adicional, permita definir uma prioridade para cada tarefa ou uma data de vencimento.

Projeto 2: Sistema de Caixa

Desenvolva um sistema que simule o funcionamento do caixa de uma loja. O usuário deverá conseguir adicionar produtos a uma compra e, ao final, visualizar o valor total da operação.

O programa deverá permitir:

  • Cadastrar produtos com nome, preço e quantidade;
  • Adicionar produtos ao carrinho de compras;
  • Listar os produtos adicionados;
  • Exibir o subtotal de cada produto;
  • Calcular o valor total da compra;
  • Aplicar um desconto quando informado;
  • Finalizar a compra e apresentar um resumo da operação.

Como desafio adicional, implemente diferentes formas de pagamento e permita calcular o troco quando o pagamento for realizado em dinheiro.

Projeto 3: Gerenciador de Filmes

Crie uma aplicação para organizar um catálogo pessoal de filmes. O sistema deverá armazenar as informações dos filmes e oferecer opções para consultar e pesquisar o catálogo.

O programa deverá permitir:

  • Cadastrar um filme informando título, gênero, ano e avaliação;
  • Listar todos os filmes cadastrados;
  • Pesquisar um filme pelo título;
  • Pesquisar filmes por gênero;
  • Exibir a avaliação de um filme;
  • Calcular a média das avaliações do catálogo;
  • Remover um filme cadastrado.

Como desafio adicional, permita ordenar os filmes por título, ano ou avaliação.

Projeto 4: Sistema Escolar

Desenvolva um sistema para gerenciar alunos e suas notas. O programa deverá permitir cadastrar estudantes, registrar suas avaliações e consultar a situação de cada aluno.

O programa deverá permitir:

  • Cadastrar um aluno com nome e matrícula;
  • Registrar as notas do aluno;
  • Calcular a média individual;
  • Informar se o aluno está aprovado, em recuperação ou reprovado;
  • Listar todos os alunos cadastrados;
  • Pesquisar um aluno pelo nome ou matrícula;
  • Calcular a média geral da turma.

Como desafio adicional, permita cadastrar diferentes disciplinas e consultar o desempenho do aluno em cada uma delas.

Projeto 5: Sistema de Biblioteca

Crie uma aplicação para administrar o acervo de uma biblioteca. O sistema deverá controlar os livros cadastrados e permitir verificar quais livros estão disponíveis ou emprestados.

O programa deverá permitir:

  • Cadastrar livros com título, autor e ano de publicação;
  • Listar todos os livros do acervo;
  • Pesquisar livros pelo título;
  • Pesquisar livros pelo autor;
  • Realizar o empréstimo de um livro;
  • Registrar a devolução de um livro;
  • Informar se um livro está disponível para empréstimo.

O sistema não deverá permitir o empréstimo de um livro que já esteja emprestado.

Como desafio adicional, registre o nome do usuário que realizou cada empréstimo e a data prevista para devolução.

Projeto 6: Sistema de Reserva de Quadra

Desenvolva um sistema para administrar reservas de horários em uma quadra esportiva. O objetivo é permitir que clientes realizem reservas sem que dois usuários ocupem o mesmo horário.

O programa deverá permitir:

  • Cadastrar clientes;
  • Consultar os clientes cadastrados;
  • Realizar uma reserva informando cliente, data e horário;
  • Listar todas as reservas realizadas;
  • Consultar as reservas de um determinado cliente;
  • Cancelar uma reserva;
  • Verificar se um horário está disponível;
  • Impedir reservas para horários que já estejam ocupados.

Como desafio adicional, permita trabalhar com diferentes quadras, horários disponíveis e valores de reserva.

Projeto 7: Jogo da Velha

Implemente o clássico jogo da velha para dois jogadores no terminal. O programa deverá apresentar um tabuleiro e permitir que cada jogador escolha uma posição para realizar sua jogada.

O programa deverá:

  • Exibir o tabuleiro antes e depois de cada jogada;
  • Permitir que dois jogadores façam suas jogadas;
  • Identificar de quem é a vez;
  • Impedir que uma posição já ocupada seja escolhida;
  • Verificar se um jogador conseguiu três símbolos em sequência;
  • Identificar situações de empate;
  • Informar o vencedor ou o empate ao final da partida;
  • Permitir iniciar uma nova partida.

Como desafio adicional, implemente um modo para jogar contra o computador. Em uma versão mais avançada, tente fazer o computador escolher suas jogadas de forma estratégica.

O FIM

Aprender Java envolve muito mais do que memorizar comandos. O principal objetivo dos exercícios é desenvolver a capacidade de analisar problemas, dividir soluções em etapas e transformar essas etapas em código.

Depois de terminar este guia, procure melhorar sua implementação no dia a dia:

  • Os nomes das variáveis estão claros?
  • Os métodos possuem responsabilidades bem definidas?
  • Existe código repetido que poderia ser reorganizado?
  • O programa trata entradas inválidas?
  • A solução poderia ser dividida em classes menores?

No fim do dia somos apenas mais um relogio quebrado que foge das horas certas. Ou quem sabe apenas mais um ser no esquema das cores.
